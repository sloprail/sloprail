# Project conventions

Never create a commit or push the developer did not ask for. "Commit this" or
"commit and push" said once is a one-time instruction, not a standing licence
for the rest of the session — a later, unrelated request does not carry that
permission forward. If you are not sure whether the CURRENT message actually
asks for a commit or a push, ask before running `git commit` or `git push`.

When you do commit, stage with `git add -A` so nothing is left behind.
