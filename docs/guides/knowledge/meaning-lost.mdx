## The failure

A long input carries details that mattered. Each time the agent restates it —
into a summary, then a summary of the summary — a detail that wasn't needed in
that moment quietly drops. No single restatement looks lossy, but the layers
compound, and there's no pointer back to the original to recover what fell away.
The meaning erodes the further the artifact drifts from its source, until what's
left is confidently wrong about what the source actually said.

## How it works

The rule refuses the drift at its root: a fact belongs in one home, stated once,
rather than re-layered into derived copies that erode. A judge reads the write and
rules on whether it re-states a fact that already has a home elsewhere.

<Steps>

1. The guardrail matches writes under the paths where this de-layering tends to
   happen.

2. A judge rules on whether the content keeps each fact in a single home rather
   than restating it into a drifting layer.

</Steps>

This is a **file-guard** with a single judge check: whether a restatement erodes
meaning is a judgment only a model reading both can make.
