## The failure

Each iteration of a long run gets decided on its own, without weighing what prior
changes already proved worked or didn't. Nothing carries the record of past
attempts into the next decision, so the loop keeps re-litigating settled ground —
retrying what already failed, discarding what already worked. It stops learning
from its own history.
