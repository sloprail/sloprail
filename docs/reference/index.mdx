Reference holds the few things you look *up*: the full command surface, a
diagnostic guide for when a rule misbehaves, and the glossary.

The rest of the exact detail — the nature YAML, the checks, the matchers, the
event fields, the `.sloprail/` layout — lives in [Guides](/guides), which is
sourced directly from the plugin's authoring skill. For what a primitive *is* and
*why*, see [Concepts](/concepts).
