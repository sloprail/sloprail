## The failure

A fact gets written into more than one place instead of referenced once. Nothing
ties the copies together, so when the fact changes one copy is updated and the
others are not. Over time they drift out of sync, and there is no way to tell
which one is right — they all look equally authoritative. The duplication that
felt harmless when written is what makes the knowledge base untrustworthy later.
