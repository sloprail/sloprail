**Completeness** requires every member of a set to be linked *somewhere*, checked mechanically; **reconciliation** is completeness as a before/after that must reduce to **empty** once exceptions and whitespace are removed. One idea: is anything unaccounted for?

The boundary with [grounding](/concepts/grounding): grounding verifies a link is *true*; reconciliation verifies a link *exists*.
